# 一.问题反馈

用户在 Maya Script Editor 中执行 `show_portfolio()` 后，AuroraView 界面已正确弹出。控制台出现一次 Win32 HWND prepare TypeError 日志，但界面正常显示，用户判断当前没有问题，要求继续开发。

# 二.⭐回顾分析

本轮继续 DCC-first 方向。当前核心不是继续做 Web 展示页，而是让作品集前端在 Maya AuroraView 宿主里调用真实 Maya API，形成可演示的 TA 工具闭环。

AuroraView v0.5.10 的 JS 调用协议为：

```javascript
await auroraview.api.method_name({ param: value })
```

Python `bind_api(MayaPortfolioApi())` 已暴露 6 个方法，足够支撑 R9.1 的首个 live scene 面板。
