# 一.问题反馈

用户确认后续开发要快速推进完整作品集，不希望每轮都跑过重、重复、边缘化的检测。当前手动操作边界需要讲清楚：Blender 和 3ds Max runtime 已完成授权和 L3 验证；常规开发不再需要用户手动介入。Maya GUI 只在采集截图/录屏时需要真实窗口。

# 二.⭐回顾分析

当前 R22 已经具备 Maya / Blender / 3ds Max / Unreal 的 runtime 证据。如果后续每轮都全量跑 npm build、mayapy Presenter Pack、Blender、Max、Unreal，会拖慢开发节奏，也会把注意力从业务插件开发带回验证本身。

更合理的长期节奏是“按变更范围验证”：只改文档就不跑 runtime；只改 Blender adapter 就跑 Blender；只改 UI 就跑 UI build；只有里程碑发布前才跑 full。
