# 一.问题反馈

R10.1 已经把 5 个模块压成一条 Maya 内资产交付业务主线，但作品集最终还需要截图和录屏素材。直接说“去截图”不可维护，需要先把该截什么、文件名、画面必须包含什么、验收标准写成可导出的证据清单。

# 二.⭐回顾分析

GUI 证据的价值不是装饰，而是证明工具确实在 DCC 内运行：

- 需要看到 Maya chrome 和 AuroraView 面板，而不是单独浏览器。
- 需要看到 Runbook 的 business route，而不是零散模块按钮。
- 需要看到 smoke gate、artifact rows 和模块 DCC 面板。
- 每张图都应对应一个业务证明点，方便后续做 portfolio case page。
