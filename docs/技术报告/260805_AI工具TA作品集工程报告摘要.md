# AI工具TA作品集工程报告摘要

## 当前发布状态

`AIToolTA_Portfolio` 当前已形成 DCC-first 作品集基线：Maya 2024 内通过 AuroraView 打开工具入口，React/TypeScript 仍作为嵌入式界面层，核心证据来自 DCC / 引擎 runtime、fixture、JSON artifact 和 Presenter Pack。

当前公开包为 `ai-tool-ta-dcc-first-showcase-r25` / `dcc-first-package@1.22.0`。R25 Presenter Pack 已收束 22/22 个关键证据文件、14 步 demo route、5 个主工具模块、Animation Continuity Maya L3、Unreal Animation Bridge import L3、Blender/3ds Max runtime L3、Unreal L3++ 和 Maya 场景事务证据；媒体门禁仍为 `CapturePending`，需要补 Maya GUI 截图和路线录屏。

## 可写入简历的项目

1. **AI Tool TA DCC-first 作品集**

   Maya 2024 + AuroraView + React/TypeScript 的 DCC 内嵌工具展示入口。价值不在网页壳，而在把 Asset Protocol、Rule Matrix、Visual Review、Texture Delivery、Task Orchestrator、Scene Transaction Guard 串成可演示、可导出、可审计的工具管线案例。

2. **跨 DCC / 引擎资产检查适配器**

   把 Lightbox 类 Pyblish 资产检查经验抽象成公开 fixture 和 rule contract。当前覆盖 Blender `bpy` L3、3ds Max `pymxs` L3、Unreal L3++ handoff inspector：关注 user properties、LOD、材质槽、UV、transform、collision、引擎 registry、平台 preset 和 waiver 边界。

3. **Maya 资产交付工具模块组**

   面向真实 TA 发布流程：协议写入与回读、规则矩阵、截图清单、贴图交付检查、dry-run 任务队列、资产放行决策、引擎导入 preflight、scene transaction diff 和 rollback preview。展示点是“工具修改了什么、为什么能放行、哪里必须阻断”。

4. **Animation Continuity / Unreal Animation Bridge**

   面向动画交付的业务正确性检查：Maya `mayapy` 创建并采集 keyed animCurve facts，把 rig identity、skeleton fingerprint、take range、sample rate、required channel、sub-frame key、root motion、scale drift 和 additive layer 变成可审计证据；Unreal Python 继续完成 Maya FBX 生成、AnimSequence / Skeleton 导入和 runtime facts 采集。

5. **MayaCraft AI 友好模块化绑定框架**

   独立探索面向 AI agent 的 Maya rig/tool 框架，目标是把绑定组件、参数协议、执行入口和模块组合方式结构化，方便后续由 agent 读取、调用和扩展。
