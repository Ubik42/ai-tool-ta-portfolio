# AI工具TA作品集工程报告摘要

## 当前发布状态

`AIToolTA_Portfolio` 当前已形成 DCC-first 作品集基线：Maya 2024 内通过 AuroraView 打开工具入口，React/TypeScript 仍作为嵌入式界面层，核心证据来自 DCC / 引擎 runtime、fixture、JSON artifact 和 Presenter Pack。

当前公开包为 `ai-tool-ta-dcc-first-showcase-r54` / `dcc-first-package@1.51.0`。R54 Presenter Pack 已收束 52/52 个关键证据文件、42 步 demo route、5 个主工具模块和跨 Maya / Blender / 3ds Max / Unreal 的 runtime 证据。最新增量是 `Unreal Gameplay Attach Fixture`：把 Maya socket/hotspot intent、Unreal attachable StaticMesh、AnimSequence 和 attach API 连成 gameplay equip 门禁；2 个 attachable 资产和 2 个动画资产存在，但 4 个角色 runtime sockets 缺失，所以 2 个 gameplay intents 正确 Blocked。媒体门禁仍为 `CapturePending`，需要补 Maya GUI 截图和路线录屏。

## 可写入简历的项目

1. **AI Tool TA DCC-first 作品集**

   Maya 2024 + AuroraView + React/TypeScript 的 DCC 内嵌工具展示入口。价值不在网页壳，而在把 Asset Protocol、Rule Matrix、Visual Review、Texture Delivery、Task Orchestrator、Scene Transaction Guard 串成可演示、可导出、可审计的工具管线案例。

2. **跨 DCC / 引擎资产检查适配器**

   把 Lightbox 类 Pyblish 资产检查经验抽象成公开 fixture 和 rule contract。当前覆盖 Blender `bpy` L3、3ds Max `pymxs` L3、3ds Max material slot -> texture manifest L3-derived、Unreal L3++ handoff inspector：关注 user properties、LOD、材质槽、贴图依赖、UV、transform、collision、引擎 registry、平台 preset 和 waiver 边界。

3. **Maya 资产交付工具模块组**

   面向真实 TA 发布流程：协议写入与回读、规则矩阵、截图清单、贴图交付检查、dry-run 任务队列、资产放行决策、引擎导入 preflight、scene transaction diff 和 rollback preview。展示点是“工具修改了什么、为什么能放行、哪里必须阻断”。

4. **Animation Continuity / Unreal Animation Bridge**

   面向动画交付的业务正确性检查：Maya `mayapy` 创建并采集 keyed animCurve facts，把 rig identity、skeleton fingerprint、take range、sample rate、required channel、sub-frame key、root motion、scale drift 和 additive layer 变成可审计证据；Unreal Python 继续完成 Maya FBX 生成、AnimSequence / Skeleton 导入和 runtime facts 采集，并用 R41 deep facts 只读验证 duration、derived frame span、frame-rate、root motion、compression metadata visibility。

5. **Character Calibration / Spatial Authoring**

   面向角色和空间挂点交付：Maya `mayapy` 采集 topology、joint coverage、face params、Control Rig mapping，以及 socket parent joint、mirror pair、hotspot semantic、pose frame、local-space 和 pose transfer approval；R35/R36 已分别把角色和空间作者 L3 flat rows 投影成可在 Maya/AuroraView 展示的 drilldown panels、owner actions 和 fix previews，R42 继续把角色 Control Rig mapping 推进到 Unreal 5.3.2 public `CR_HeroFace` fixture authoring、runtime hierarchy controls 和 post-authoring bridge；R43 进一步只读链接 Control Rig controls、Maya deformation targets、Unreal Skeleton bones 和 compile API visibility，揭示 controls presence 不等于绑定可交付；R44 用 Maya FBX + Unreal import 建立 public `SK_HeroFace_Skeleton`，把 `Eye_L`、`Eye_R`、`Jaw` target 缺口 3 / 3 resolved；R45 调用 public `CR_HeroFace` compile 方法并记录 diagnostic/status 边界，证明 compile 可调用但不能假装 direct diagnostics 已可读；R38 把 Spatial Authoring drilldown 接到 Unreal SkeletalMesh / Skeleton socket API 和 expected socket coverage；R40 通过 controlled executor 证明 UE 5.3 Python 无法可靠写入 socket identity，形成正确的 API-limited gate。

6. **Platform Variant Forge**

   面向 PC -> Mobile 资产派生：把目标路径、owner approval、triangle/texture/material/draw-call budget、LOD coverage、Nanite、shader feature、collision policy、Unreal runtime facts、材质贴图依赖事实和 public Texture2D payload 合成可审计 variant plan，并把 drift 转成 dry-run generation operations。展示点是“平台降级为什么能自动做、哪里必须阻断、引擎里实际是否达标、下一步生成动作如何受控执行”。

7. **MayaCraft AI 友好模块化绑定框架**

   独立探索面向 AI agent 的 Maya rig/tool 框架，目标是把绑定组件、参数协议、执行入口和模块组合方式结构化，方便后续由 agent 读取、调用和扩展。
