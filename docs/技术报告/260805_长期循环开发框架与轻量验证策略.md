## 2. 循环开发节奏

每轮只闭环一个高价值业务任务，不做散点堆叠。

标准交付顺序：

1. 选一个 Lightbox 高价值业务点。
2. 写 public-safe schema / fixture。
3. 写 DCC 或 engine collector，把真实软件事实归一化。
4. 写 rule evaluation / decision / fix preview。
5. 导出 JSON artifact。
6. 接入 Presenter Pack / public manifest。
7. 同步模块文档和开发日志。
8. 跑对应档位验证。

一轮的完成定义：

- 有明确业务问题，不只是新增 UI 卡片。
- 有 fixture 或 runtime 证据。
- 有机器可读 artifact。
- 有 Presenter Pack 或 public package 可发现路径。
- 有文档说明当前 gate、边界、下一步。

## 3. 轻量验证档位

默认使用 `<repo>\scripts\validate_loop.ps1`。

| 档位 | 命令 | 什么时候跑 | 覆盖 |
| --- | --- | --- | --- |
| quick | `.\scripts\validate_loop.ps1 -Tier quick` | 每轮默认 | Python 编译、核心 JSON manifest |
| package | `.\scripts\validate_loop.ps1 -Tier package` | 改 Presenter Pack / manifest / public package 时 | quick + Maya mayapy build pack smoke |
| ui | `.\scripts\validate_loop.ps1 -Tier ui` | 改 React/TypeScript UI 或 bridge 数据模型时 | quick + `npm run build` |
| animation | `.\scripts\validate_loop.ps1 -Tier animation` | 改 Animation Continuity Lab 时 | quick + animation contract smoke |
| unreal-animation | `.\scripts\validate_loop.ps1 -Tier unreal-animation` | 改 Unreal Animation Bridge 时 | quick + bridge contract smoke + Unreal import L3 harness |
| spatial-authoring | `.\scripts\validate_loop.ps1 -Tier spatial-authoring` | 改 Spatial Authoring Workbench 时 | quick + spatial contract smoke + Maya L3 |
| platform-variant | `.\scripts\validate_loop.ps1 -Tier platform-variant` | 改 Platform Variant Forge 时 | quick + platform variant contract smoke |
| platform-variant-unreal | `.\scripts\validate_loop.ps1 -Tier platform-variant-unreal` | 改 Platform Variant Unreal Runtime Probe 时 | quick + Unreal runtime-vs-plan probe |
| platform-variant-generation | `.\scripts\validate_loop.ps1 -Tier platform-variant-generation` | 改 Platform Variant Generation Planner 时 | quick + runtime drift to dry-run generation plan |
| platform-variant-texture | `.\scripts\validate_loop.ps1 -Tier platform-variant-texture` | 改 Platform Variant Texture Runtime Collector 时 | quick + Unreal material / Texture2D runtime probe |
| blender | `.\scripts\validate_loop.ps1 -Tier blender` | 改 Blender adapter / fixture / rule 时 | quick + Blender `bpy` L3 |
| max | `.\scripts\validate_loop.ps1 -Tier max` | 改 3ds Max adapter / fixture / rule 时 | quick + 3ds Max `pymxs` L3 |
| full | `.\scripts\validate_loop.ps1 -Tier full` | 里程碑发布前 | quick + package + ui + Blender L3 + Max L3 |

跳过规则：

- 只改文档：不跑 DCC runtime。
- 只改 Maya API：跑 `quick`，必要时加 `package`。
- 只改 React UI：跑 `ui`，不跑 Blender/Max/Unreal。
- 只改 Blender adapter：跑 `blender`，不跑 Max 和 npm build。
- 只改 Max adapter：跑 `max`，不跑 Blender 和 npm build。
- 只改 Platform Variant Forge：跑 `platform-variant`，如果只接 Presenter Pack 再加 `package`。
- 只改 Platform Variant Unreal Runtime Probe：跑 `platform-variant-unreal`，如果只接 Presenter Pack 再加 `package`。
- 只改 Platform Variant Generation Planner：跑 `platform-variant-generation`，如果只接 Presenter Pack 再加 `package`。
- 只改 Platform Variant Texture Runtime Collector：跑 `platform-variant-texture`，如果只接 Presenter Pack 再加 `package`。
- 只有发布包升级或 final handoff 前才跑 `full`。
