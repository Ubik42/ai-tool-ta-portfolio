## Portfolio Split

The portfolio is intentionally split into five tools rather than one oversized demo:

| Tool | Business value |
| --- | --- |
| Asset Protocol Workbench | Turns asset handoff into a typed protocol with aliases, severity policy, and exportable evidence. |
| Cross-DCC Rule Matrix | Shows how one QA rule becomes different DCC checks, fix previews, and manual-only dispositions. |
| Visual Review Studio | Converts subjective visual review into rubric lanes, pass contracts, and structured evidence. |
| Texture Delivery Console | Separates dry-run texture delivery from approved mutation and package delta tracking. |
| Task Orchestrator | Aggregates receipts, signoffs, evidence manifests, dependency impact paths, and the public package release gate. |

The core TA claim is not that AI replaces pipeline logic. The claim is that AI can speed authoring, explanation, review triage, and package narration while deterministic code owns schema, validation, mutation, and release gates.
